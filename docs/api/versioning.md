# Версионирование контрактов

Статус: implemented

- **HTTP API**: версия в пути (`/api/v1`). Ломающее изменение → `/api/v2`,
  v1 сопровождается на период deprecation. Неломающие изменения (новые поля
  ответов, новые endpoints) версию не меняют; клиенты обязаны игнорировать
  неизвестные поля.
- **Real-time события**: версия в имени события (`message.created.v1`).
  Изменение payload → `*.v2` + новая схема; старая схема не удаляется,
  пока событие может быть отправлено.
- **OpenAPI**: `info.version` следует SemVer релиза; собранный
  `openapi/dist/openapi.json` коммитится, CI проверяет отсутствие диффа
  (`./tools/chat openapi validate`).
- **Релиз**: SemVer по подписанному тегу (см. CI/CD, этап 12).
