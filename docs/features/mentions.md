# Упоминания

Статус: implemented

## Сценарии

- Ввод `@` в строке ввода открывает всплывающее меню участников комнаты;
  дальнейший ввод фильтрует его по началу ника и по вхождению в имя
  (совпадения по нику идут первыми, показывается не больше пяти).
- Строка кандидата: аватарка в кольце личного оттенка с зелёной отметкой
  присутствия, ник `@username` с подсветкой совпавшей части и имя человека.
- Клавиатура: `↑`/`↓` двигают выбор по кругу, `Enter` и `Tab` вставляют,
  `Escape` закрывает меню (до следующей правки текста оно не всплывает);
  пока меню открыто, `Enter` не отправляет сообщение и не переносит строку.
- Вставка идёт на место набранного `@…` у каретки: окружающий текст остаётся,
  каретка встаёт сразу после `@username `.
- В ленте `@ник` рисуется акцентным бейджем; своё упоминание выделено
  янтарным. Сообщение, где тегнули читающего (`mentions` содержит его id),
  получает акцентную полосу у края пузыря.

## Реализация

- Клиент передаёт `mentions: [user_id…]` (валидация: ULID, существующие
  пользователи, ≤ 20); VO `MentionList` дедуплицирует.
- Хранятся в JSON-колонке `messages.mentions`; доставка уведомлений — этап 8.
- Ник участника отдаётся в составе комнаты (`Member.username`) через контракт
  `Mentionable` (`packages/backend/shared-kernel`) — пакет чата не знает класс
  пользователя приложения.
- UI: `MentionPicker` (+ чистая `filterMentionCandidates`), клавиатура и
  вставка — в `ChatScreen`, бейджи и подсветка — в `MessageBubble`.
