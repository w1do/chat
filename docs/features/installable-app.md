# Установка приложения и версия для компьютера

Статус: implemented

## Установка на устройство (PWA)

Чат — веб-приложение, но ставится как обычное: браузер предлагает добавить его
на домашний экран телефона или в список приложений компьютера. Установленное
приложение открывается своим окном, без адресной строки.

Подсказка об установке показывается один раз, когда браузер сообщает, что
установка возможна; отказ запоминается локально.

**На iPhone установка обязательна для push-уведомлений** — Safari присылает их
только установленным приложениям.

## Без сети

Service worker отдаёт понятный экран «Нет связи» вместо страницы ошибки
браузера. Переписка в кеш не складывается намеренно: закешированная лента
показывала бы вчерашние сообщения как свежие, а после возврата связи
приложение и так досинхронизирует историю по HTTP.

## Изображения на устройстве

Однажды показанная картинка открывается мгновенно и без сети: миниатюры
вложений и изображения профилей и комнат живут в отдельном кеше
`chat-images-v1` по стратегии «сначала кеш». Оригиналы вложений и данные API
в него не попадают — с телефона оригинал может весить десятки мегабайт, а
закешированная лента показывала бы вчерашние сообщения как свежие.

- Пределы: не больше 400 записей и не больше 2 МБ на запись. При переполнении
  удаляются записи, к которым дольше всего не обращались.
- Ответы с ошибкой не сохраняются вовсе — в том числе 404 ещё не готовой
  миниатюры, иначе она осталась бы «навсегда неготовой» на этом устройстве.
- Отказ хранилища не ломает показ: изображение приходит из сети, а человек
  ошибки не видит.
- Прогрев: при открытии списка переписок подгружаются изображения комнат, при
  загрузке истории — миниатюры её ближайших сообщений. Прогрев ждёт простоя
  приложения, держит не больше трёх одновременных обращений и не запрашивает
  адрес повторно, поэтому не соперничает с живой перепиской за канал.
- Очистка: кеш изображений удаляется целиком при выходе из аккаунта, при
  отзыве токена (401 после входа) и когда `/me` вернул другого человека — на
  общем устройстве чужие фотографии не остаются доступными даже без сети.

## Обновление

Новая версия скачивается в фоне; приложение сообщает о ней и применяет по
подтверждению либо при следующем запуске. Service worker отдаётся без кеша,
поэтому установка не «залипает» на старой версии.

## Версия для компьютера

От ширины окна 1024 px приложение показывает две колонки: слева список комнат,
справа переписка. Раскладка выбирается **по размеру окна, а не по user-agent** —
он врёт на планшетах и в режиме рабочего стола браузера. Пока комната не
выбрана, правая колонка объясняет, что делать, а не пустует. Сужение окна
возвращает одноколоночный вид и не теряет открытую комнату. Колонки
прокручиваются независимо: длинный список комнат не двигает переписку, а окно
браузера не прокручивается вовсе.

## Проверки

- `./tools/chat web test` — регистрация service worker, обработчики push и
  клика по уведомлению, кеш изображений (перехват, вытеснение, отказ
  хранилища, очистка), прогрев, подсказка об установке, `useMediaQuery`;
- `./tools/chat e2e desktop` — две колонки, отправка сообщения, переключение
  раскладки при сужении окна и работа с клавиатуры;
- заголовки отдачи проверяются на собранном образе:
  `curl -I http://localhost:8080/sw.js` — `no-store`.
