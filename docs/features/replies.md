# Ответы на сообщения

Статус: implemented

- `reply_to_id` в пределах той же комнаты (чужая комната → 422); self-FK
  с `restrictOnDelete`.
- Мягкое удаление родителя сохраняет связь: ответ показывает контекст
  «Сообщение удалено».
- UI: действие «Ответить» на самом сообщении, цитата над композером с автором
  и отменой, кликабельная цитата в ленте переносит к оригиналу и подсвечивает
  его на пару секунд; для удалённого оригинала цитата говорит «Сообщение
  удалено», связь сохраняется.

Проверки: package-тест «soft deletes preserving replies», feature-тест
«foreign reply targets», компонентные тесты: начать ответ, отменить, отправить
с целью, перейти к оригиналу, удалённый оригинал.

Запуск: `./tools/chat test chat`, `./tools/chat test api`, `./tools/chat web test chat`.

Ответ начинается свайпом сообщения влево (как в Telegram) или пунктом
«Ответить» в меню действий — долгое нажатие на телефоне, правый клик на
компьютере, `Enter` с клавиатуры. Отдельной кнопки у сообщения больше нет.
