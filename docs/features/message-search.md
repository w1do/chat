# Поиск по сообщениям

Статус: implemented

## Что это

Поиск по истории комнат, в которых состоит спрашивающий. PostgreSQL остаётся
источником истины: индекс Typesense хранит только идентификаторы и текст и
всегда перестраивается командой.

Поиск **выключен по умолчанию** (`SEARCH_ENABLED=false`): чат полностью
работоспособен без поискового сервиса.

## Границы доступа

Индекс отдаёт только идентификаторы. Список комнат берётся из `room_members`
запрашивающего, фильтр по комнатам уходит в запрос, а тела сообщений
дочитываются из PostgreSQL с повторной проверкой комнаты. Поэтому:

- не участник не получает ни сообщения приватной комнаты, ни признака, что оно
  существует — ответ выглядит как «ничего не нашлось»;
- мягко удалённое сообщение не возвращается, даже если индекс ещё не догнал;
- системные записи (кто вошёл, кто вышел) не индексируются вовсе.

## Что лежит в индексе

Только безопасные поля: `id`, `room_id`, `author_id`, `body`, `created_at`.
Ни имён, ни почты, ни названия комнаты — всё остальное подтягивается из базы
уже после проверки прав.

## Индексация

Доменные события `MessageCreated/Updated/Deleted` (публикуются после commit)
ставят `SyncMessageIndexJob` в очередь `search`. Задание приводит документ к
текущему состоянию строки: нет строки, она удалена или системная — документ
удаляется, иначе перезаписывается (`upsert`). Отсюда идемпотентность: повтор и
любой порядок заданий дают одинаковый результат, а откатившаяся транзакция в
индекс не попадает, потому что читать нечего.

Провал задания пишет в журнал класс ошибки без текста сообщения; расхождение
лечится переиндексацией.

## API

`GET /api/v1/search/messages?q=&room_id=&limit=` — см. OpenAPI dist.
Недоступный или выключенный индекс — `503` с кодом `service_unavailable`;
детали Typesense и ключ наружу не выносятся.

## Интерфейс

Кнопка поиска в шапке комнаты открывает лист поиска: запрос от двух символов,
результаты с автором и временем, переход к сообщению. Раздельные состояния —
«ищем», «ничего не нашлось», «поиск недоступен, чат работает как обычно» и
«сообщение вне загруженной истории».

## Проверки

- `./tools/chat test chat` — конфигурация, безопасные поля, индексация после
  commit и её отсутствие после отката, правка и удаление, идемпотентность,
  границы доступа, деградация;
- `./tools/chat test api tests/Feature/SearchTest.php` — эндпоинт: находит своё,
  молчит о чужом, отвечает 503, валидирует запрос;
- `./tools/chat web test chat` — лист поиска (5 тестов);
- `./tools/chat smoke search` — настоящий Typesense: документ проиндексирован и
  найден.
