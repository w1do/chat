# Мобильный интерфейс

Статус: implemented

Продуктовый интерфейс собран из прототипа мобильного чата (каталог `chat/`
в корне — исходная вёрстка) и связан с реальным API.

## Раскладка (STRUCTURE.md §4)

- `packages/frontend/ui` — дизайн-система без продуктовой логики: токены
  светлой/тёмной темы (`styles/tokens.ts`), анимации и safe-area
  (`styles/global.css`), примитивы `Avatar`/`Dots`/`Toggle`/`Segmented`/
  `Sheet`/`Row`/`Group`/`Toast`, хуки `useKeyboardInsets`, `useElementHeight`,
  `useTheme`.
- `packages/frontend/chat` — экраны: `RoomsScreen` (список комнат, счётчики
  непрочитанного, создание комнаты), `ChatScreen` (лента с группировкой по
  автору, дни, ответы, реакции, упоминания, набор текста, состояние
  соединения), `MagicSheet` (помощник).
- `apps/chat-web` — оболочка: вкладки «Чаты»/«Настройки», слой переписки,
  экран участников, локальные настройки (тема, размер текста, анимации,
  «печатает», Enter отправляет).

## Соответствие домену

Прототип описывал «семейный» чат с ролями owner/parent/teen/child/guest и
доступом по ролям. Бэкенд этого не знает, поэтому интерфейс использует
реальную модель:

| Прототип | Реализация |
|---|---|
| роли семьи | роли комнаты: `owner`, `admin`, `member` |
| readRoles/writeRoles | `visibility` (public/private) + членство |
| аватар и цвет участника | выводятся из идентификатора (`voiceHue`, инициал) |
| эмодзи комнаты | выводится из названия (`roomEmoji`) |
| магическая кнопка | `MagicSheet`; активна только при `ai.enabled` в `/config.json` |
| статусы доставки | «отправляется» (оптимистично) / «отправлено» (сохранено) |
| вложения, голос | не входят в MVP |

## Что добавлено в API ради интерфейса

- `unread_count` в `GET /rooms` — счётчик непрочитанного по комнатам, где
  пользователь состоит (для чужих комнат — `null`);
- `POST /rooms/{room}/read` — отметка прочтения (не двигается назад).
