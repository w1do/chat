# Изображения профиля и комнаты

Статус: verified (E2E `./tools/chat e2e profile-images`)

Аватарка человека, набор его прежних аватарок, личные обои переписки и
фотография комнаты. Все файлы живут в объектном хранилище (ADR-011) и
хранятся только подготовленными в webp.

## Аватарка

Человек загружает изображение в настройках профиля, и оно сразу становится
текущим: показывается в списке участников, в переписке и в самих настройках.
Пока аватарки нет — рисуется буква имени с постоянным личным оттенком; она же
остаётся запасным видом, если картинка не загрузилась.

Загруженные аватарки **копятся**. Из набора выбирается та, что показывается
сейчас: выбор прежней не перезагружает файл, а переводит указатель. Любую
можно удалить; если удалена текущая — показываться начинает другая из набора,
а когда набор опустел, возвращается буква имени. Снять текущую, сохранив
набор, — отдельное действие.

**Набор виден только его владельцу.** Остальным доступна лишь текущая
аватарка. Это осознанное расхождение с привычным поведением больших
мессенджеров, где история аватарок публична: человек, меняющий фотографию,
обычно не рассчитывает, что все прежние остаются доступны любому.

Пределы задаёт установка: размер файла (`PROFILE_IMAGE_MAX_KB`, по умолчанию
8 МБ) и число аватарок в наборе (`PROFILE_MAX_AVATARS`, по умолчанию 12). При
заполненном наборе загрузка отклоняется с 409 и понятным сообщением.

## Обои переписки

Обои — личная настройка: их видит только тот, кто поставил. Собеседник в той
же комнате видит свой фон. Обои действуют во всех переписках этого человека;
вернуть обычный фон можно в любой момент.

Поверх обоев лежит подложка, сохраняющая читаемость текста в светлой и тёмной
теме: человек приносит любое изображение, а сообщения обязаны остаться
читаемыми.

## Фотография комнаты

Фотографию ставят владелец и админ — то же право, что и на название с
описанием. Обычный участник действия не видит и получает 403 при прямом
запросе; для постороннего приватной комнаты не существует (404).

Фотография одна: новая вытесняет прежнюю вместе с её файлами, набора прежних у
комнаты нет. Пока фотографии нет, комната показана эмодзи, выведенным из
названия — оно же остаётся запасным видом. Удаление комнаты уносит её
фотографию из хранилища.

## Хранение и выдача

- Исходники не хранятся: файл приводится к webp нужного размера **до**
  попадания в хранилище. Это отличает оформительские картинки от вложений в
  переписке, где исходник обязан сохраняться как прислан.
- Два размера: крупный (512 px — профиль и шапка) и мелкий (128 px — списки и
  ленты). Мелкий готовится конверсией в очереди `media`; пока он не готов,
  отдаётся крупный, а интерфейс показывает прежний вид.
- Бакет закрыт: файлы отдаёт приложение, проверив право. Аватарку получает
  любой вошедший — она и так видна в списках участников; обои — только их
  владелец; фотографию комнаты — те, кому видна сама комната.
- В адресе изображения стоит идентификатор медиа, поэтому адрес меняется
  вместе с картинкой и ответ кэшируется надолго.

## API

- `GET/POST /me/avatars`, `PATCH/DELETE /me/avatars/{avatar}`,
  `DELETE /me/avatar`
- `POST/DELETE /me/wallpaper`
- `POST/DELETE /rooms/{room}/photo`
- Файлы: `GET /avatars/{image}`, `/avatars/{image}/thumb`,
  `/wallpapers/{image}`, `/room-photos/{image}`, `/room-photos/{image}/thumb`

Адреса изображений приходят в представлениях: `avatar_url` и
`avatar_large_url` у человека, `avatar_url` у участника комнаты,
`author_avatar_url` у сообщения, `photo_url` и `photo_large_url` у комнаты.
Отсутствие изображения — это `null`, а не пустая строка: по нему интерфейс
выбирает запасной вид.

Схемы real-time событий не менялись: аватарка в payload не отправляется —
лента берёт её из состава комнаты, который и так загружен.

## Edge cases

- Не изображение или превышение размера → 422, прежняя картинка остаётся.
- Заполненный набор аватарок → 409 с указанием предела.
- Удаление текущей аватарки → показываться начинает другая; пустой набор →
  буква имени.
- Конверсия ещё не готова → отдаётся крупный размер, интерфейс не показывает
  пустоту.
- Картинка не загрузилась у смотрящего → буква имени или эмодзи комнаты.

## Критерии приёмки / проверки

- `./tools/chat test packages`, `./tools/chat test api`,
  `./tools/chat web test chat`, `./tools/chat web test identity`,
  `./tools/chat web test ui` — проходят.

Запуск E2E: `./tools/chat e2e profile-images` — человек ставит аватарку,
владелец ставит фотографию комнаты, второй участник видит аватарку картинкой.
