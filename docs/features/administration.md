# Администрирование и аудит

Статус: implemented

## Что это

Минимум, необходимый, чтобы держать установку в рабочем состоянии: состояние
зависимостей, выключатель AI-помощника и журнал значимых действий. Это API,
а не панель: ни Blade, ни Inertia, ни Filament (STRUCTURE.md §«administration»).

## Права

Права объявляет пакет, выдаёт приложение (ADR-010):

| Право | Что открывает |
|---|---|
| `administration.system.view` | состояние и текущие выключатели |
| `administration.settings.update` | изменение выключателей |
| `administration.audit.view` | журнал |

Роль `super-admin` открывает всё через `Gate::before`; отдельное право можно
выдать и без роли — тогда доступен только соответствующий раздел. Каждый
`/admin/*` маршрут закрыт правом; гость получает 401, пользователь без
права — 403.

Первый администратор назначается на сервере:

```bash
php artisan chat:grant-admin <логин>
```

Команда создаёт роль `super-admin` со всеми правами пакета и выдаёт её
пользователю.

## Состояние

`GET /api/v1/admin/status` отдаёт те же компоненты, что и
`/api/v1/readiness` (база, Redis, очереди, WebSocket, поиск) — второй источник
правды не заводится, — плюс включённость AI и поиска и версию.

## Выключатель AI

`PATCH /api/v1/admin/settings {"ai_enabled": false}` сохраняет значение в
`system_settings`. Оно применяется к каждому запросу middleware
`ApplyRuntimeSettings`: конфигурацию Octane восстанавливает между запросами,
поэтому значение не «залипает» в worker'е. Выключенный помощник отвечает
документированным 503, **переписка при этом работает как обычно**.

## Журнал

`GET /api/v1/admin/audit-logs?action=&actor_id=&cursor=&limit=` — новые записи
первыми, cursor-пагинация. Пишутся административные изменения
(`administration.settings.updated`) и обращения к AI
(`ai.revision.succeeded|failed|timed_out`) — последние приходят событием
`RevisionRecorded` из пакета `ai`, связка живёт в `PackageWiringProvider`.

В контексте только безопасные метаданные. Значения ключей, похожих на секрет
или приватный текст (`*key*`, `*token*`, `*password*`, `*prompt*`,
`*suggestion*`, `*body*`, `*text*`, `*email*`), заменяются на `[redacted]`,
длинные строки обрезаются. Числа и флаги не редактируются, поэтому счётчики
токенов остаются читаемыми. Журнал не должен становиться вторым хранилищем
приватного текста (CLAUDE.md §11).

## Horizon

Dashboard закрыт gate `viewHorizon`: доступ только у `super-admin`,
неаутентифицированный запрос отклоняется.

## Интерфейс

Экран `/admin`: состояние компонентов, переключатель AI, журнал с фильтром по
действию. Пункт в настройках появляется, только если админский эндпоинт
ответил успехом, а прямой переход по адресу без прав показывает
«Этот раздел доступен только администратору».

- `./tools/chat web test` — экран администратора (4 теста).
