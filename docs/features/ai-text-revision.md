# AI-редактирование черновика

Статус: verified (E2E `./tools/chat e2e ai-revision`)

## Сценарии

- Пользователь пишет черновик и нажимает «помощника» в композере.
- Доступные операции: исправить (`fix`), понятнее (`clarify`), короче
  (`shorten`), подробнее (`expand`), мягче (`tone`), произвольная инструкция
  (`custom`).
- Ответ — предложение рядом с исходным текстом. Черновик заменяется **только**
  по нажатию «Заменить черновик»; рядом есть «Оставить своё», а после замены —
  «Вернуть мой текст».
- Ожидание можно отменить кнопкой; отмена не оставляет висящих запросов.
- Интерфейс прямо говорит, что текст обработан внешним ИИ.

## Права и ограничения

| Ограничение | Значение по умолчанию | Настройка |
|---|---|---|
| Длина ввода | 2000 символов | `AI_MAX_INPUT_LENGTH` |
| Таймаут | 20 с | `AI_TIMEOUT_SECONDS` |
| Квота на пользователя | 6/мин, 60/час | `AI_PER_USER_MINUTE`, `AI_PER_USER_HOURLY` |
| Повторы | 1, только для сетевого сбоя | `AI_RETRIES` |
| Circuit breaker | 5 отказов → пауза 60 с | `AI_BREAKER_*` |

Помощник выключается администратором (`AI_ENABLED=false`): endpoint отвечает
503, кнопка показывает замок, отправка сообщений работает как обычно.

## Приватность

Наружу уходит только присланный текст и системный промпт операции — история
комнаты не передаётся (проверяется тестом на реальном HTTP-запросе). В аудите
`ai_requests` хранятся операция, пользователь, поставщик, модель, статус,
токены, стоимость, длина ввода, длительность и короткая причина отказа; ни
промпта, ни ответа, ни ключей. Подробности — ADR-006.

## Реализация

- Backend: `packages/backend/ai` — контракт `TextRevisionProvider`,
  `PolzaProvider` (OpenAI-совместимый API Polza), `NullProvider`,
  `FakeTextRevisionProvider`; `ReviseDraftHandler` с квотами, таймаутом,
  повтором и circuit breaker; `POST /api/v1/ai/message-revisions`.
- Frontend: `useRevision` и `MagicSheet` в `packages/frontend/chat`,
  кнопка помощника в композере `ChatScreen`.

## Проверки

- `./tools/chat test ai` — 20 тестов: успех, отказ, таймаут, квота, лимит
  длины, выключенный помощник, размыкание цепи, аудит без приватного текста;
- `./tools/chat test api tests/Integration/AiRevisionTest.php` — сквозной путь,
  envelope ошибки без утечек, работа чата при выключенном AI, отправка только
  черновика в HTTP-запросе;
- `./tools/chat web test chat` — лист помощника: запуск операции, отмена,
  принятие, отказ, выключенное состояние;
- `./tools/chat smoke polza` — необязательная проверка против настоящего Polza
  (нужен `AI_API_KEY`, в обычном CI пропускается).

Запуск E2E: `./tools/chat e2e ai-revision` — помощник предлагает, а не публикует;
при выключенном помощнике это сказано словами, и сообщение всё равно уходит.
