владение данными

Переписка остаётся на вашем диске

Никакого внешнего control plane и телеметрии: приложение работает автономно, а резервная копия — обычный pg_dump.

PostgreSQL у вас

Сообщения, участники и файлы живут в вашей базе и вашем объектном хранилище.

Без обязательных третьих сторон

Помощник выключен по умолчанию; включив его, вы сами выбираете провайдера.

Открытый код и честные статусы

Тесты, документация и статус каждой функции лежат в репозитории.

Честная граница: сквозного шифрования нет — администратор сервера технически может прочитать переписку. Это заявленное ограничение, а не недоработка формулировки.

интерфейс

Одинаково удобно с телефона и с компьютера

Оболочка владеет экраном: страница не отскакивает, панель ввода видна целиком, клавиатура не уводит переписку вниз. От 1024 px — две колонки.

  • Светлая и тёмная тема, размер текста
  • Полная работа с клавиатуры и видимый фокус
  • Установка на телефон и компьютер как приложение

комнаты и роли

Публичные и приватные комнаты с понятными правами

У комнаты один владелец. Он правит название и описание, архивирует или удаляет комнату; админ помогает с участниками; участник просто общается.

  • Приглашение по нику из списка подходящих пользователей
  • Исключение участника: владелец — любого кроме себя, админ — только участника
  • Выход из комнаты и системная запись об этом прямо в истории

сообщения

Ответы, реакции, упоминания — без лишних кнопок в ленте

Действия живут в жестах: свайп влево — ответить, двойное касание — «❤️», долгое нажатие или правый клик — меню. Всё то же доступно с клавиатуры.

  • Правка в течение окна редактирования и мягкое удаление с сохранением ответов
  • Бесконечная история с курсорной пагинацией и счётчиками непрочитанного
  • Повторная отправка не создаёт дубль — запрос идемпотентен

Звонков и сквозного шифрования в продукте нет.

real-time

WebSocket доставляет, HTTP восстанавливает

События идут через собственный сервер Reverb после фиксации транзакции. Если связь оборвалась, история досинхронизируется по HTTP — источник истины остаётся на сервере, а не в сокете.

приглашения

Ссылка на семь дней, которую можно отозвать

Приглашение создаёт участник комнаты. Ссылка многоразовая, живёт семь дней и отзывается в один клик; в базе хранится только хэш токена.

  • Гость называет имя, логин и пароль генерируются за него
  • Подсказка в настройках напоминает задать свой пароль
  • Частота выдачи ссылок ограничена

файлы и оформление

Вложения, галерея и личные обои переписки

Файлы загружаются в границах комнаты: белый список типов, пределы размера и количества, запрет исполняемого. Публичных ссылок нет — файл отдаёт приложение тому, кто вправе прочитать сообщение.

  • Плитки: один файл крупно, 2–4 сеткой, дальше «Показать ещё»
  • Галерея со свайпом и управлением с клавиатуры
  • Аватарка профиля с набором прежних, фотография комнаты, свои обои

уведомления

Только когда вас нет в комнате

Источник истины — реестр присутствия: если вы сейчас читаете комнату, уведомление не придёт. Шумная беседа сворачивается в одну запись со счётчиком.

  • Каналы — лента и почта — настраивает сам пользователь
  • Web Push доставляет при закрытом приложении, если заданы ключи VAPID
  • Приложение ставится на телефон и компьютер, есть экран «Нет связи»

Это веб-push через подписку браузера, а не нативный клиент.

поиск

Мгновенно и только по вашим комнатам

Индекс на Typesense хранит безопасные поля и обновляется после фиксации транзакции, а доступ к найденному подтверждается запросом в PostgreSQL.

  • Выключен по умолчанию — включается, когда действительно нужен
  • Недоступность поиска отвечает документированной деградацией, чат продолжает работать
  • Индекс перестраивается командой chat:search-reindex

помощник

Правит черновик и всегда спрашивает разрешение

Помощник предлагает вариант вашего черновика: исправить ошибки, сказать понятнее, короче или мягче. Опубликовать может только человек — кнопкой «Принять».

  • Наружу уходит только текст черновика, без истории комнаты
  • Провайдер, модель, таймаут и квоты задаются конфигурацией; есть отмена
  • Выключен по умолчанию, администратор может выключить его в любой момент
  • Аудит фиксирует обращение без промпта и ответа

Текст обрабатывает внешний AI-провайдер, который вы выбираете сами.

администрирование

Столько управления, сколько нужно оператору

Состояние сервисов, выключатель помощника и журнал значимых действий. Права проверяются на сервере, роль администратора выдаётся консольной командой.

  • Готовность зависимостей — отдельная проверка без утечки деталей
  • Пароль пользователю оператор может задать из консоли
  • Никакой аналитики и телеметрии наружу

архитектура

Один self-hosted контур, без микросервисов

Модульный монолит: Laravel-пакеты за композиционным корнем, React-пакеты в приложении, восемь сервисов Docker Compose. Kubernetes не нужен.

контур установки
  • PHP 8.4 · Laravel
  • React 19 · TypeScript strict
  • PostgreSQL · Redis · Reverb
  • OpenAPI 3.1 как источник истины

Минимум для стека — 2 vCPU и 2 ГБ памяти; поиск и помощник отключаются, если не нужны.

установка

Одна команда на чистом VPS

Стек сам сгенерирует ключ приложения, применит миграции, создаст поисковый индекс и поднимет сервисы. Дальше — открыть адрес, зарегистрироваться первым и создать комнату.

  • Обновление — git pull && docker compose up -d --build
  • Резервная копия — обычный pg_dump
  • За панелью с Traefik второй compose-файл не нужен

Это демонстрационная страница: команда только копируется, здесь ничего не выполняется.

root@vps:~
git clone https://github.com/w1do/chat.git && cd chat
docker compose -f docker-compose.yml -f docker-compose.standalone.yml up -d --build

  • Building api, web … done
  • Applying migrations … done
  • Starting postgres, redis, api, web, worker, scheduler, reverb, typesense
  • readiness: ok — открывайте адрес в браузере
