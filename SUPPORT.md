# Поддержка

## Прежде чем писать

1. [docs/operations/troubleshooting.md](docs/operations/troubleshooting.md) —
   частые поломки установки;
2. `./tools/chat smoke runtime` — что именно не готово;
3. `docker compose -p chat logs api worker reverb --tail 200`.

## Куда обращаться

| Вопрос | Куда |
|---|---|
| Ошибка в продукте | GitHub Issues: версия, шаги, ожидаемое и фактическое поведение, фрагмент логов без секретов |
| Вопрос по установке | GitHub Discussions |
| Уязвимость | **не** в issue — см. [SECURITY.md](SECURITY.md) |
| Коммерческая поддержка и лицензирование | указывается владельцем установки при форке |

## Что приложить к issue

- версия (`docker compose -p chat exec api php artisan --version` и тег образа);
- вывод `/api/v1/readiness`;
- шаги воспроизведения на чистой установке.

Логи и `.env` очищайте от паролей, ключей и приватной переписки.

## Чего поддержка не покрывает

Настройку чужой инфраструктуры (DNS, почтовый провайдер, прокси), доработку
под конкретный бизнес-процесс и восстановление данных без резервной копии.
