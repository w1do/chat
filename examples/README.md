# Так выглядит приложение

Снимки сделаны на живом стенде: реальные аккаунты, реальная переписка, ничего
не дорисовано. Телефон — 390×844, рабочий стол — 1440×900.

Пересобрать: поднять стек `./tools/chat up` и прогнать генератор
`apps/chat-web/e2e/screenshots.spec.ts` тем же контейнером Playwright, что и
`./tools/chat e2e`.
