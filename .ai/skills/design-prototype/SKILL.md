# Design Prototype (NeuralFlow AI/RAG)

This skill is intended for the rapid prototyping of interactive interfaces for AI services and RAG systems. It is based on the "BotSync NeuralFlow" design system, optimized for high-tech artificial intelligence components.

## Core Concepts

- **Transparency**: Visualize internal AI processes (Thinking Trace, Chain of Thought, Retrieval steps).
- **Industrial Precision**: Use strict grids, glassmorphism, and monumental typography.
- **Interactivity**: Animated transitions, "live" 3D objects, and dynamic performance metrics.

## Visual Language

- **Accent Colors**: 
  - `Neural Gold` (#C8A645) — for AI-driven insights and active states.
  - `Logic Blue` (#4A90E2) — for data connections and background logic.
- **Surface**: `Dark Surface Glass` with `backdrop-blur-md`.
- **Typography**: 
  - `DM Serif Display` — for monumental headings.
  - `DM Sans` — for data-dense interfaces and body text.

## How to Use

1. **Identify the AI Stage**: Determine which part of the RAG pipeline needs visualization (e.g., query analysis, document fetching, or final generation).
2. **Select Components**: Use specialized components like `<ThinkingTrace />`, `<SourceCitation />`, or `<KnowledgeGraph />`.
3. **Implement Glassmorphism**: Apply consistent `backdrop-blur` and border-opacity to all overlays.
4. **Data Visualization**: Include reliability evidence (e.g., source confidence scores, retrieval latency metrics).

## Termination Checklist

- [ ] Headlines use `DM Serif Display`.
- [ ] Blocks have rounded corners between `10px` and `20px`.
- [ ] Key elements use "Lock-in" entry animations.
- [ ] AI reliability markers (sources, accuracy metrics) are present.
- [ ] Interface follows the four-layer DDD principles in its data structure.
