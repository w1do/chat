# Безопасность

## Поддерживаемые версии

Исправления безопасности выходят для текущей минорной версии. Обновляйтесь до
последнего патча — предыдущие минорные ветки не патчатся.

## Сообщить об уязвимости

Пишите на **security@example.com** (в форке замените на свой контакт), не
открывая публичный issue. Сроки ответа, область и правила безопасного
тестирования — [docs/security/disclosure.md](docs/security/disclosure.md).

## Тем, кто разворачивает

- обязательный чек-лист — [docs/security/hardening.md](docs/security/hardening.md);
- модель угроз — [docs/security/threat-model.md](docs/security/threat-model.md);
- ротация секретов — [docs/security/secret-rotation.md](docs/security/secret-rotation.md).

Сквозного шифрования сообщений в MVP нет: администратор сервера технически
может прочитать переписку. Это осознанная граница продукта.
