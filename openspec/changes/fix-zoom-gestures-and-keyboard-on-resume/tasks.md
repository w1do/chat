## 1. Жест перестаёт менять масштаб

- [x] 1.1 Задать оболочке `touch-action: pan-x pan-y` (именно так, а не `manipulation`: тот разрешает щипок) и убедиться, что прокрутка, инерция, долгое нажатие и свайп по сообщению не сломались — прогнать `./tools/chat web test chat` и `./tools/chat web test` целиком
- [x] 1.2 Подавить в оболочке `gesturestart`/`gesturechange`/`gestureend` с `passive: false` — щипок в Safari; проверить компонентным тестом, что слушатели ставятся и снимаются и что событию вызывается `preventDefault`
- [x] 1.3 Проверить компонентным тестом, что двойной тап по сообщению по-прежнему обрабатывается приложением как двойное нажатие, а не теряется вместе с зумом

## 2. Оболочка перестаёт путать масштаб с клавиатурой

- [x] 2.1 Учесть `visualViewport.scale` в `useKeyboardInsets`: при масштабе заметно больше единицы (сравнение с допуском, не строгое равенство) клавиатура считается нулевой, а сдвиг не применяется; покрыть тестами хука случаи «увеличено и клавиатура закрыта», «увеличено и вьюпорт сдвинут», «масштаб вернулся к единице»
- [x] 2.2 Проверить тестом хука, что браузер без `scale` в `visualViewport` ведёт себя как раньше и ничего не выдумывает — рядом с существующей проверкой «без visualViewport»

## 3. Возврат из фона

- [x] 3.1 Добавить в `useKeyboardInsets` перемер по событиям возврата — `visibilitychange` документа, `pageshow` и `focus` окна; проверить тестами, что после возврата с устаревшими числами геометрия обновляется, в том числе когда клавиатура закрылась в фоне
- [x] 3.2 Обновлять состояние только при действительном изменении чисел; закрепить тестом, что повторный перемер с теми же значениями не вызывает лишний рендер
- [x] 3.3 Повторять измерение серией после события возврата (сразу, после кадра и с возрастающими паузами примерно до секунды); проверить тестами хука, что при геометрии, устаканивающейся с задержкой, побеждает последнее измерение и что серия не даёт лишних рендеров
- [x] 3.4 Добавить ограничитель: при увеличенной странице высота не меньше `window.innerHeight`; проверить тестами хука случаи «увеличено — оболочка занимает окно целиком», «увеличено и вьюпорт сдвинут» и «клавиатура открыта — сжатие сохраняется»
- [x] 3.5 Закрасить фон документа цветом темы и синхронизировать его при смене темы; проверить компонентным тестом, что фон меняется вместе с темой
- [x] 3.6 Проверить тестом снятие всех слушателей при размонтировании — включая новые
