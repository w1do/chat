# Add Password Reveal Toggle

## Why

Пароль вводят вслепую. На телефоне, где клавиатура мелкая и промахнуться легко,
человек узнаёт об опечатке только после отказа — а при регистрации и смене
пароля не узнаёт вовсе: он придумал пароль, ошибся в нём и сохранил ошибку.
Единственный способ проверить себя — стереть и набрать заново.

Кнопка показа пароля есть в любом современном интерфейсе, и её отсутствие
воспринимается как недоделка. В приложении сейчас четыре поля пароля, и ни у
одного такой возможности нет.

## What Changes

- **Введённый пароль можно посмотреть**: у каждого поля пароля появляется
  переключатель показа — при входе, регистрации и смене пароля (текущий и
  новый).
- **По умолчанию пароль скрыт**, показ включает сам человек и только для того
  поля, где нажал.
- **Показ не портит пароль**: на телефоне для открытого поля выключаются
  автозаглавные буквы, автокоррекция и проверка орфографии — иначе система
  молча правит набранное и отправляет его на сторонний сервис проверки.
- **Отправка формы возвращает поле в скрытое состояние**, чтобы браузер
  по-прежнему предлагал сохранить пароль.
- **Переключатель работает с клавиатуры** и объявляет своё состояние
  вспомогательным технологиям.
- Попутно чинится видимая рамка фокуса — во всех полях форм, а не только в
  полях пароля: сейчас она не появляется вовсе, а с новой кнопкой внутри поля
  клавиатурный пользователь без неё не поймёт, где находится.

## Capabilities

### New Capabilities

Новых нет.

### Modified Capabilities

- `identity/authentication-and-profile`: к правилам форм входа, регистрации и
  смены пароля добавляется показ введённого пароля по требованию человека — с
  условиями, при которых показ безопасен и не мешает вводу.

## Impact

- `packages/frontend/identity`: компонент `Field` (общий рендерер полей всех
  форм) и четыре поля пароля в `LoginForm`, `RegisterForm`, `PasswordForm`;
  манифест пакета — библиотека иконок объявляется явной peer-зависимостью.
- `packages/frontend/ui`: правило видимого фокуса в общих стилях.
- Тесты форм и E2E-сценарии, которые заполняют пароль.
- `docs/features/authentication.md`, `docs/features/mobile-ui.md`.
