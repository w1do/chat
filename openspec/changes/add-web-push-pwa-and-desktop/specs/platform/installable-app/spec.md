## Purpose

Приложение ставится на домашний экран телефона и в список приложений
компьютера, запускается своим окном и переживает потерю сети без пустой
страницы.

## ADDED Requirements

### Requirement: Приложение устанавливается на устройство

Приложение SHALL предоставлять манифест с именем, иконками, цветами и
стартовым адресом, достаточный для установки браузером.

#### Scenario: Установка на телефон

- **WHEN** пользователь открывает чат в поддерживающем браузере и выбирает
  «Установить»
- **THEN** приложение появляется на домашнем экране и запускается в
  отдельном окне без адресной строки

#### Scenario: Подсказка об установке

- **WHEN** браузер сообщает, что установка доступна, а пользователь ещё не
  устанавливал приложение и не отклонял подсказку
- **THEN** приложение один раз предлагает установку и запоминает ответ

### Requirement: Приложение переживает потерю сети

При отсутствии сети приложение SHALL показывать понятный экран вместо ошибки
браузера.

#### Scenario: Открытие без сети

- **WHEN** пользователь открывает установленное приложение без сети
- **THEN** показывается оболочка приложения с сообщением об отсутствии связи,
  а не страница ошибки браузера

#### Scenario: Возврат сети

- **WHEN** связь восстанавливается
- **THEN** приложение синхронизирует данные обычным способом, без ручной
  перезагрузки

### Requirement: Обновление приложения не требует ручных действий

Установленное приложение SHALL получать новую версию после её выкладки без
переустановки.

#### Scenario: Вышла новая версия

- **WHEN** на сервере выложена новая версия, а приложение открыто
- **THEN** пользователю сообщается о доступном обновлении, и оно применяется
  после подтверждения или при следующем запуске

#### Scenario: Кеш не отдаёт устаревший код

- **WHEN** приложение обновилось
- **THEN** оно не использует устаревшие файлы предыдущей версии
