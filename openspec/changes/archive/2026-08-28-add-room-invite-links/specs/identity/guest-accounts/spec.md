## Purpose

Аккаунт, который появляется у человека, пришедшего по приглашению: он создан
за него, поэтому продукт обязан объяснить, чем такой аккаунт ограничен и как
сделать его своим.

## ADDED Requirements

### Requirement: Аккаунт создаётся по приглашению

Переход по действующему приглашению SHALL создавать аккаунт для человека без
учётной записи: логин и пароль генерируются системой, отображаемое имя человек
указывает сам.

#### Scenario: Первый вход по ссылке

- **WHEN** человек без аккаунта открывает действующую ссылку и указывает имя
- **THEN** для него создаётся аккаунт с этим именем, он входит в систему и
  оказывается в комнате приглашения

#### Scenario: Имя не указано

- **WHEN** человек не указал имя
- **THEN** аккаунт не создаётся, а форма объясняет, что нужно сделать

#### Scenario: Логин уникален

- **WHEN** аккаунт создаётся автоматически
- **THEN** его логин не совпадает с существующими и подходит для последующего
  входа

#### Scenario: Почта не запрашивается

- **WHEN** аккаунт создан по приглашению
- **THEN** почта остаётся незаполненной и не требуется для работы чата

### Requirement: Человеку объясняют, что аккаунт не настроен

Пока пользователь не задал собственный пароль, приложение SHALL показывать,
что вход держится на текущей сессии, и предлагать задать логин и пароль.

#### Scenario: Подсказка в настройках

- **WHEN** пользователь, пришедший по приглашению, открывает настройки
- **THEN** он видит объяснение и приглашение задать свой логин и пароль

#### Scenario: Пароль задан

- **WHEN** пользователь задал собственный пароль
- **THEN** подсказка исчезает, аккаунт ничем не отличается от обычного

#### Scenario: Смена логина

- **WHEN** пользователь меняет автоматически выданный логин на свой
- **THEN** новый логин действует для входа, а прежний освобождается

### Requirement: Уже вошедший пользователь не получает второй аккаунт

Если по ссылке переходит аутентифицированный пользователь, система SHALL
использовать его аккаунт.

#### Scenario: Свой пользователь по ссылке

- **WHEN** вошедший пользователь открывает ссылку-приглашение
- **THEN** новый аккаунт не создаётся, он просто вступает в комнату
