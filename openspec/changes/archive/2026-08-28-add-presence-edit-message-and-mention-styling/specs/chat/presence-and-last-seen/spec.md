## Purpose

Определяет поведение отслеживания, синхронизации и отображения статуса присутствия пользователей (онлайн) и времени их последней активности (last seen) в чате и профилях.

## ADDED Requirements

### Requirement: User presence and last active timestamp tracking
Система ДОЛЖНА отслеживать активность пользователя в чате и обновлять метку времени последней активности `last_seen_at` при аутентифицированных действиях (отправка сообщений, чтение, взаимодействие через WebSocket).

#### Scenario: User performs an action and last seen updates
- **WHEN** аутентифицированный пользователь отправляет сообщение, отмечает комнату прочитанной или подключается к presence-каналу
- **THEN** система обновляет значение `last_seen_at` для данного пользователя в базе данных/кэше

### Requirement: Presence and last seen representation in API
Система ДОЛЖНА возвращать статус присутствия (`is_online`) и метку времени последнего визита (`last_seen_at`) в ответах API для профиля пользователя, списков участников комнат и участников личных диалогов.

#### Scenario: Fetching room members with presence
- **WHEN** клиент запрашивает список участников комнаты через `/api/v1/rooms/{room}/members`
- **THEN** каждый участник в ответе содержит актуальные поля `is_online` и `last_seen_at`

#### Scenario: Fetching user profile or direct conversation
- **WHEN** клиент запрашивает данные пользователя или диалога
- **THEN** в ресурсе пользователя передаются статус онлайна и время последней активности

### Requirement: Realtime presence status updates
Система ДОЛЖНА в реальном времени информировать участников комнат и диалогов об изменении статуса присутствия пользователей (вход в сеть / выход из сети).

#### Scenario: User connects to chat
- **WHEN** пользователь подключается к WebSocket-каналам приложения
- **THEN** другим подключённым участникам транслируется событие присутствия со статусом онлайн для данного пользователя

#### Scenario: User disconnects from chat
- **WHEN** соединение пользователя разрывается или истекает тайм-аут активности
- **THEN** клиенты обновляют статус пользователя на оффлайн и фиксируют актуальное время последнего визита `last_seen_at`

### Requirement: Human-readable last seen formatting in UI
Клиентское приложение ДОЛЖНО отображать понятный человеку статус активности пользователя («В сети», «был(а) в сети только что», «был(а) в сети 10 минут назад», «был(а) в сети сегодня в 14:30», «был(а) в сети вчера в 19:15», либо дату).

#### Scenario: User is currently online
- **WHEN** собеседник находится в сети
- **THEN** в шапке диалога и карточке участника отображается зелёный индикатор присутствия и текст «В сети»

#### Scenario: User is offline with known last seen timestamp
- **WHEN** собеседник не в сети и известно время `last_seen_at`
- **THEN** в шапке чата и списке участников выводится статус в формате «был(а) в сети <относительное или точное время>»
