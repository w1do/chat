## Purpose

Определяет функциональные требования к редактированию отправленных текстовых сообщений автором, пользовательскому интерфейсу изменения текста и доставке обновлений участникам комнаты.

## ADDED Requirements

### Requirement: Author can edit sent text message
Система ДОЛЖНА позволять автору редактировать текст ранее отправленного сообщения в течение разрешённого политикой времени.

#### Scenario: Author initiates message edit
- **WHEN** автор выбирает своё сообщение и нажимает действие «Редактировать»
- **THEN** поле ввода переходит в режим редактирования с исходным текстом выбранного сообщения и возможностью внести правки

#### Scenario: Author saves edited message
- **WHEN** автор вносит изменения в текст сообщения и подтверждает сохранение
- **THEN** система обновляет текст сообщения в хранилище, проставляет время изменения `edited_at` и статус `is_edited = true`

#### Scenario: Author cancels message edit
- **WHEN** автор нажимает кнопку отмены (или клавишу Escape) в режиме редактирования
- **THEN** поле ввода сбрасывается к обычному состоянию черновика без изменения исходного сообщения

### Requirement: Non-authors cannot edit other users' messages
Система ДОЛЖНА запрещать редактирование чужих сообщений рядовыми участниками и возвращать ошибку авторизации при попытке несанкционированного изменения.

#### Scenario: Member tries to edit another user's message
- **WHEN** пользователь пытается отправить запрос на изменение сообщения, автором которого он не является
- **THEN** система отклоняет запрос с HTTP статусом 403 Forbidden

### Requirement: Realtime synchronization of edited messages
Система ДОЛЖНА транслировать событие `message.updated.v1` всем активным участникам комнаты после успешного сохранения изменений.

#### Scenario: Message updated broadcast received by room members
- **WHEN** сообщение отредактировано на сервере
- **THEN** все подключённые к комнате клиенты получают событие `message.updated.v1` и обновляют отображение текста сообщения в ленте без перезагрузки

### Requirement: Visual indicator for edited messages
Клиентское приложение ДОЛЖНО отображать признак `(отредактировано)` у сообщений, которые подвергались правке.

#### Scenario: Displaying edited message in feed
- **WHEN** сообщение имеет флаг `is_edited = true`
- **THEN** в теле или метаданных сообщения отображается ненавязчивая метка `(отредактировано)` рядом со временем отправки
