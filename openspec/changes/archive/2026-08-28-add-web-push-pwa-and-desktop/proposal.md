# Add Web Push, PWA And Desktop Layout

## Why

Чат догоняет мессенджер по ощущениям, но не по достижимости. Сегодня человек
узнаёт о новом сообщении, только пока держит вкладку открытой: уведомления
браузера ставит сам SPA, и с закрытым чатом они не приходят. На телефон
приложение не поставить — только вкладка в браузере. На компьютере
показывается тот же узкий мобильный экран посреди широкого монитора.

Для семейного чата это решающие вещи: если о сообщении не узнают до вечера,
им перестанут пользоваться, а если чат нельзя поставить на домашний экран, он
проигрывает привычному мессенджеру ещё до первого сообщения.

## What Changes

- **Настоящие push-уведомления**: сервер отправляет их через Web Push с
  ключами VAPID, поэтому сообщение доходит и при закрытом приложении. Push —
  новый канал доставки рядом с лентой и почтой, подчиняющийся уже
  существующим правилам: только тому, кого нет в комнате, с группировкой и
  предпочтениями по категориям.
- **Приложение устанавливается на устройство (PWA)**: манифест, иконки,
  service worker, оффлайн-заглушка и подсказка об установке. На iPhone это
  ещё и условие работы push.
- **Версия для компьютера**: на широком экране — две колонки (список комнат
  слева, переписка справа) вместо мобильного экрана по центру. Раскладка
  выбирается по ширине окна, а не по user-agent.
- **Тумблер push в настройках**: выключен — подписка снимается и системные
  уведомления не приходят вовсе. Лента уведомлений и письма продолжают
  работать как раньше.

## Capabilities

### New Capabilities

- `notifications/web-push`: доставка push-уведомлений через Web Push —
  подписки устройств, отправка после commit, правила приватности содержимого,
  снятие подписки и обработка отказов push-сервиса.
- `platform/installable-app`: установка приложения на устройство —
  манифест, service worker, оффлайн-поведение и подсказка об установке.
- `platform/desktop-layout`: раскладка для широких экранов и правила
  переключения между мобильным и десктопным видом.

### Modified Capabilities

- `notifications/offline-delivery`: к каналам `database` и `mail` добавляется
  `push`; правило «не уведомлять того, кто в комнате» и группировка
  распространяются на него без изменений.

## Impact

- `packages/backend/notifications`: новый канал `push`, таблица подписок,
  отправитель Web Push, задание доставки, endpoints подписки/отписки,
  настройки категорий.
- `apps/chat-api`: конфигурация VAPID, консольная команда генерации ключей,
  связка с существующим `PackageWiringProvider`.
- Новая зависимость composer для подписи и шифрования Web Push (в offline-
  окружении ставится через контейнер с сетью).
- `apps/chat-web`: манифест и иконки, service worker (push + оффлайн-заглушка),
  подписка на push и тумблер в настройках, две колонки на широком экране.
- `packages/frontend/chat` и `packages/frontend/ui`: раскладка, не завязанная
  на мобильную ширину.
- `infra/docker/web`: отдача манифеста и service worker с корректными
  заголовками кеширования.
- Документация: `docs/features/notifications.md`, новые разделы про PWA и
  десктоп, `docs/operations/configuration.md` (ключи VAPID).
