## Purpose
Обеспечить корректное отображение и взаимодействие UI приглашения участников комнаты на мобильных экранах, без выхода за пределы экрана и с предсказуемой прокруткой.

## Requirements

### Requirement: Invite UI fully visible on mobile
Экран/диалог приглашения участников SHALL полностью умещаться в вьюпорте на ширине ≤ 640px, без выхода за границы и с корректными внутренними отступами.

#### Scenario: Invite dialog fits viewport
- **WHEN** пользователь открывает приглашение в комнате на мобильном устройстве
- **THEN** заголовок, поле ввода/поиска и основные действия полностью видимы без горизонтального скролла

### Requirement: Scrollable content with fixed actions
Содержимое списка пользователей SHALL прокручиваться вертикально, а панель действий (основные кнопки) остаётся закреплённой и доступной.

#### Scenario: Long member list
- **WHEN** список потенциальных участников длинный
- **THEN** список прокручивается; кнопки подтверждения/закрытия остаются на месте и доступны без прокрутки назад

### Requirement: Touch targets and spacing
Интерактивные элементы SHALL иметь минимальный размер тач-таргета 44×44pt и достаточные отступы, чтобы избежать ложных нажатий.

#### Scenario: Selecting a user via touch
- **WHEN** пользователь выбирает участника касанием
- **THEN** элемент легко нажимается; нет перекрытий и ложных срабатываний на соседних элементах

### Requirement: Safe-area and viewport adjustments
Invite UI SHALL учитывать safe-area insets и изменение высоты вьюпорта при появлении клавиатуры, не перекрывая критичные элементы.

#### Scenario: Keyboard overlaps search field
- **WHEN** пользователь фокусирует поле поиска с открытой клавиатурой
- **THEN** поле поиска остаётся видимым; критичные кнопки не перекрываются клавиатурой
