## Purpose

Определяет требования к пользовательскому интерфейсу интерактивного автодополнения упоминаний пользователей (@mentions) при вводе сообщений, подсветке аватарок и форматированию тегов.

## Requirements

### Requirement: Mention autocomplete trigger and filtering
Система SHALL открывать всплывающее меню вариантов упоминания при вводе символа `@` в поле ввода сообщения и фильтровать участников комнаты по введённому префиксу никнейма или имени.

#### Scenario: User types @ in message composer
- **WHEN** пользователь вводит символ `@` в поле ввода сообщения
- **THEN** открывается всплывающее окно `MentionPicker` со списком участников текущей комнаты

#### Scenario: User filters mentions by typing
- **WHEN** пользователь продолжает ввод текста после `@` (например, `@alex`)
- **THEN** список участников мгновенно фильтруется по совпадению с никнеймом или отображаемым именем

### Requirement: Visual presentation of mention candidates
Элементы списка автодополнения SHALL отображать аватарку участника с акцентным кольцом/подсветкой, индикатор онлайн-статуса, никнейм и отображаемое имя.

#### Scenario: Displaying candidate row with avatar and status
- **WHEN** открыто всплывающее меню автодополнения
- **THEN** для каждого кандидата отображается аватарка (или инициалы при отсутствии изображения), цветное выделение при фокусе/наведении, статус присутствия и имя пользователя

### Requirement: Keyboard and pointer selection of mentions
Система SHALL поддерживать выбор участника как кликом/тапом, так и с помощью клавиатуры (стрелки Вверх/Вниз для перемещения, Enter/Tab для вставки, Escape для закрытия меню).

#### Scenario: User navigates and selects candidate via keyboard
- **WHEN** пользователь нажимает стрелки Вверх/Вниз для перемещения по списку и нажимает Enter
- **THEN** выбранный никнейм вставляется в поле ввода в формате `@username `, всплывающее меню закрывается, и фокус возвращается в текстовое поле

### Requirement: Styled rendering of mentions in messages
Клиентское приложение SHALL визуально выделять теги упоминаний в сообщениях интерактивным бейджем и подсвечивать фон сообщения, если текущий пользователь был тегнут.

#### Scenario: Viewing message with mention
- **WHEN** пользователь просматривает сообщение, содержащее `@username`
- **THEN** упоминание рендерится как стилизованный кликабельный бейдж с акцентным цветом

#### Scenario: Current user is mentioned
- **WHEN** в сообщении упомянут текущий авторизованный пользователь
- **THEN** пузырь сообщения получает заметную акцентную подсветку/маркер для привлечения внимания
