### Callbacks (Webhooks)
- [Status Change Callback](https://docs.platega.io/callback-%D0%BE%D0%B1-%D0%B8%D0%B7%D0%BC%D0%B5%D0%BD%D0%B5%D0%BD%D0%B8%D0%B8-%D1%81%D1%82%D0%B0%D1%82%D1%83%D1%81%D0%B0-%D1%82%D1%80%D0%B0%D0%BD%D0%B7%D0%B0%D0%BA%D1%86%D0%B8%D0%B8-29209725e0.md)
  - **Verification**: Headers `X-MerchantId` and `X-Secret` are provided.
  - **Statuses**: `CONFIRMED`, `CANCELED`, `CHARGEBACKED`.
  - **Retry Policy**: Up to 3 retries at 5-minute intervals if no `200 OK` is received within 60 seconds.

## Integration Best Practices

1. **Amount Units**: Always verify if the API expects integers (kopecks/cents) or decimals (rubles/dollars). Most Platega endpoints expect decimals in requests but might return integers in callbacks.
2. **Idempotency**: Webhook handlers must be idempotent to handle retries correctly.
3. **Security**: Validate `X-Secret` using `hash_equals()` to prevent timing attacks.
